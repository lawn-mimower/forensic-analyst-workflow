# Indian Forensic Compliance Study Guide — Index

A structured study guide for forensic analysts checking Indian company documents against compliance laws. Covers all major regulatory bodies, acts, and professional standards.

## How to Use This Guide

1. **Start with Part 1** (Foundations) to understand the institutional landscape
2. **Work through Parts 2-5** based on the document types you're analyzing
3. **Part 6** maps every resource to your pipeline categories for practical integration
4. **Part 7** provides the recommended reading order

## Source Material

The guide refers to downloaded ICAI, ICSI, BPRD and FIU publications by file name (for example `pdfs/ICAI_CARO_2020_Guidance_Note.pdf`). Those PDFs are not included in this repository, and neither is the IPC/CrPC JSON data referenced as `structured-data/Indian-Law-Penal-Code-Json/`; download them from the issuing bodies. `../structured-data/manual_download_urls.json` lists sources that need a manual download.
